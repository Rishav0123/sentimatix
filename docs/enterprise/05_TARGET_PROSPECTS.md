# Sentimatix: Enterprise Prospect List

This document outlines key target companies, their potential use case for Sentimatix, and general contact points. 

> **Tip for finding decision makers:** For enterprise B2B sales, generic `info@` emails have a very low response rate. Use this list in combination with **LinkedIn** to find the "Product Manager", "Data Engineer", or "Head of Partnerships" at these specific companies. You can then use tools like [Hunter.io](https://hunter.io/) or [Apollo.io](https://apollo.io/) to verify their exact email using the standard corporate patterns below.

**Cold Outreach Workflow:**
1. Pick 3 companies from this list (e.g., Dhan, Tickertape, Tradetron).
2. Search LinkedIn for *"Product Manager Data [Company Name]"* or *"Head of Partnerships [Company Name]"*.
3. Guess their direct email using the patterns above, or plug their name into Hunter.io.
4. Send a short, punchy email attaching the **One-Pager PDF**, the **Sample Dataset CSV**, and linking directly to the interactive `/docs`.
